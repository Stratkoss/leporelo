# Leporelo

Native macOS app (Swift 6, SwiftUI + AppKit, PhotoKit) that turns Apple Photos into a print-ready photo book. Core logic lives in the UI-free package `LeporeloCore`; the app is a thin layer on top. The user interface is **Czech**; keep UI strings Czech. Docs: `README.md` (English), `README.cs.md` (Czech, has the supplier-profile format and the full list of known limits).

## Commands

Run from the repo root. The Makefile pins `DEVELOPER_DIR` to `/Applications/Xcode.app/...` because `xcode-select` points at Command Line Tools that lack the Testing module. Do not change system settings.

- `make test` core tests (`swift test`)
- `make test-app` generates the project and runs app tests
- `make build-app` / `make run-app` build and launch the Debug app
- `make cli` builds `.build/debug/leporelo-cli` (run it from there, it needs the `Leporelo_LeporeloCore.bundle` next to it)
- `App/Leporelo.xcodeproj` is generated by XcodeGen from `App/project.yml` and is gitignored. Edit `project.yml`, never the xcodeproj.

## Layout

- `Sources/LeporeloCore/`: Model, Source, Analysis, Scoring, Grouping, Layout (drafting, planning, snapping, margins), Render, Export, Project (the `.leporelo` package), Supplier (profiles), Pipeline, Workflow. Must not depend on UI.
- `Sources/leporelo-cli/`: thin CLI over `Workflow`.
- `App/Leporelo/Sources/`: Start, NewAlbum, Triage, Editor, Export, Layouts, Background, PhotoKit, Shared.
- Tests: `Tests/LeporeloCoreTests` and `App/LeporeloTests` (Swift Testing, not XCTest).
- `docs/superpowers/specs|plans/`: design docs and implementation plans per feature; new features get a spec and a plan there. `docs/manual-verification.md`: what automated tests cannot cover.

## Conventions and gotchas

- Swift 6 language mode everywhere. Closures handed to `Task.detached` must capture `let` values, not `var` (a `var` made Xcode 27.2 reject the build).
- Supplier profiles are data: a JSON file in `Sources/LeporeloCore/Resources/Profiles` is enough. Unverified numbers keep `"verified": false`.
- Background writes into an open document go through `NSFileCoordinator` and the document, otherwise autosave overwrites them.
- Default book margin is 6 mm (adjustable, up to 30 mm); every edit keeps frames and text inside it (`MarginRule`).
- Tests hit the real disk and Vision. A full disk produces many bogus "isn't enough space" and analysis failures (about 1 GB free was not enough); check `df -h` before chasing them.
- Photos access, real PhotoKit behaviour and a real Canva order are not covered by tests; see `docs/manual-verification.md`.
- Commits follow `feat:` / `fix:` / `docs:` prefixes. Work on a branch or worktree, merge to `main`.
